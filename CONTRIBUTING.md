# Contributing

Start with `FEATURES.md` and `TASKS.md`. This is pre-MVP: useful contributions include fixtures, browser behavior, and the next JavaScript/DOM integration work. A browser executable and local interaction check are available; see `docs/RUNNING.md`. The general automated experiment runner is still planned.

Open an issue to coordinate larger work, then submit a focused PR linked to a feature. Include the problem, observable behavior, reproducible validation and limitations. Update feature acceptance, the daily log and generated website status with your contribution. Humans and agents use the same review bar; no paid model is required.

Use `AGENTS.md` for the workflow and `docs/AUTORESEARCH.md` for experiment design. Keep evaluator/corpus changes separate from engine changes scored against them. Never include credentials or captured private browsing data.
