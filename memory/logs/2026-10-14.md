## v0.9.5: Classic external script loading (`<script src>`), Performance Dashboard, CLI profiler, and rendering caches

- **Intent**: Address user request for (1) implementing external script loading (`<script src="...">`), (2) adding a Performance Dashboard and profiling utilities to diagnose where UI/scroll hangs come from, and (3) eliminating those hangs.
- **Implementation**:
  - `crates/mg-chassis/src/net.rs`, `crates/mg-chassis/src/resources.rs`, `crates/mg-sparkle/src/js_browser.rs`, `crates/mg-sparkle/src/js_browser/boa.rs`: Added `ResourceKind::Script` and `resources::prepare_script_html` to preload up to 16 classic external scripts per page (up to 256 KiB per script within the 1 MiB page-script source budget) before invoking the network-free restricted Linux script worker. Forged `<!--mg-external-scripts:` prefixes in untrusted page HTML are stripped, `-->` sequences inside the JSON transport header are escaped as `--\u003e`, and `Window` `onclick`/`onsubmit` accessors are now configurable per WebIDL (while `location` remains `LegacyUnforgeable`) so external scripts like Hacker News's `hn.js` execute cleanly without `TypeError: cannot declare global function`.
  - `crates/mg-chassis/src/devtools.rs`, `crates/mg-chassis/src/lib.rs`, `src/main.rs`: Added a third **Performance** tab to the native Inspector (`F12` / `Ctrl+Shift+I` → `Performance`, or `Ctrl+Shift+P` shortcut) and a headless CLI profiler (`mgbrowser --profile <URL>`) that prints page-load phase timings (HTML fetch, parse, subresources, external scripts, Boa JS worker opcodes/memory), slowest subresources/external scripts, and live render/scroll/hover repaint benchmarks.
  - `crates/mg-chassis/src/lib.rs`, `crates/mg-sparkle/src/render.rs`, `crates/mg-sparkle/src/styled_layout.rs`, `crates/mg-sparkle/src/paint.rs`: Added three rendering caches after profiling `https://news.ycombinator.com/`:
    1. **Frame Cache** (`mg-chassis`): Reuses the rendered `Frame` during pointer hover, context-menu, inspector and chrome updates (~0.51 ms repaint vs ~2,563 ms previously).
    2. **Stylo Computed-Style Cache** (`mg-sparkle::render::StyleCache`): Reuses computed CSS styles across scroll repaints when the DOM and viewport dimensions are unchanged (`0.00 ms` style pass on scroll).
    3. **RustyBuzz Shaping & Width Cache** (`mg-sparkle::paint::Fonts`): Caches shaped glyph runs and widths (`SHAPE_CACHE_ENTRIES = 4096`, `SHAPE_CACHE_BYTES = 1 MiB`) so layout and painting do not re-parse and re-shape the OpenType face on every word, cutting uncached Hacker News layout from ~2,100 ms to ~314 ms and cached scroll repaints to ~39 ms in debug builds (~4 ms in release builds).
