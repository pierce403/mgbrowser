# 2026-10-14 Work Log (America/Los_Angeles)

## v0.9.4: Link hover URL preview, open link in new tab (right-click & Ctrl+click), default Boa ECMAScript, and DOM bindings

- **Intent**: Address user requests for (1) link hover destination preview in the bottom-left status bar and right-clicking a link to open in a new tab, (2) `Ctrl+click` on a link opening in a new tab, and (3) enabling pure-Rust Boa ECMAScript execution by default (with `--disable-scripts` opt-out) along with expanded DOM bindings (`classList`, `dataset`, `[Symbol.iterator]` on collections, and boolean attribute reflection), then ship and install `v0.9.4`.
- **Implementation**:
  - `crates/mg-chassis/src/lib.rs`, `crates/mg-chassis/src/chrome.rs`, `crates/mg-chassis/src/scroll.rs`, `src/desktop.rs`: Added `pointer_move`, `hovered_link`, and `link_at` hit-testing in `Browser`, wired X11 `MotionNotify` and `LeaveNotify` events (`EventMask::LEAVE_WINDOW`), and updated the bottom-left status strip (`x = 10, y = height - 22`) to display the hovered or context-targeted link URL in `palette.ink`.
  - `crates/mg-chassis/src/devtools.rs`, `crates/mg-chassis/src/lib.rs`, `src/desktop.rs`: Extended `devtools::State` with `context_link: Option<String>`. Right-clicking a link renders a 3-button context menu (`Open link in new tab`, `Inspect element`, `Close`), while non-link elements retain the 2-button context menu (`Inspect element`, `Close`). Added `Action::OpenLinkInNewTab`, `new_tab_request`, `take_new_tab_request()`, and `pointer_down_with_modifiers` / `pointer_up_with_modifiers` so both the context menu action and `Ctrl+click` on a link open a new tab via `Desktop::fresh_tab`.
  - `src/main.rs`, `src/restart.rs`, `crates/mg-chassis/src/lib.rs`: Enabled `app.set_scripts_enabled(true)` and `restart_scripts = true` by default on launch (`--disable-scripts` opts out; `--enable-scripts` remains accepted), and preserved loaded stylesheets/resources when falling back from a rejected >1 MiB script worker request.
  - `crates/mg-sparkle/src/js_browser.rs`, `crates/mg-sparkle/src/js_browser/boa.rs`, `crates/mg-sparkle/tests/boa_pages.rs`: Added `Element.classList` (`add`, `remove`, `contains`, `toggle`, `replace`, `item`, `value`, `length`, `toString`), `Element.dataset` (`data-*` attribute reflection), `[Symbol.iterator]` and `forEach`/`values`/`entries`/`keys` on DOM collections and `classList`, and boolean attribute reflection (`defer`, `async`, `hidden`, `disabled`, `checked`, `required`, `readOnly`, `multiple`, `selected`).
