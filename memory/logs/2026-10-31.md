## Root-Cause Audit: `slashdot.org` Warnings & Systematic Real-Site Compatibility (`v0.9.29`)

### Intent & Why These Classes of Issues Were Previously Missed

1. **Same-origin stylesheet restriction & missing `@import` (`crates/mg-chassis/src/net.rs`, `resources.rs`)**:
   - Local fixtures and WPT reftests served CSS from the same loopback origin and without `@import`. On live sites (`slashdot.org`'s `https://a.fsdn.com/sd/classic.ssl.css`, CDN stylesheets, `@import` chains), `ResourceKind::Stylesheet` previously rejected cross-origin HTTPS URLs while `Image` and `Script` already used credential-free cross-origin HTTPS. Upgraded `Stylesheet` to the identical credential-free HTTPS policy (stripping cookies across origins and rejecting plain HTTP cross-origin or HTTPS->HTTP downgrades) and added bounded `@import` loading (depth `<= 4`, cycle-checked, line/column-preserving blanking) inside unchanged `MAX_SHEETS = 16`, `MAX_REQUESTS = 32`, and `MAX_TOTAL = 2 MiB` limits.
2. **DevTools Console surfacing CSS Syntax §5 parse fallbacks & legacy `-moz-border-radius` (`crates/mg-chassis/src/devtools.rs`, `crates/mg-sparkle/src/style.rs`)**:
   - Per CSS Syntax Module Level 3 §5, unknown properties (`font-weignt:normal`), legacy vendor prefixes (`-moz-border-radius`), unitless non-zero lengths (`padding-top: 1`), and bare `!important` tokens are ignored declarations so progressive fallback works silently; Chromium DevTools never logs them as Console warnings. Filtered `css-parse` out of DevTools Console counts/rows while retaining `css-unsupported`, `image-unsupported`, `layout-fallback`, and `style-fallback`, and added byte-length-preserving author CSS normalization for `-moz-border-radius` (plus corner variants, `-moz-box-sizing`, `-webkit-box-sizing`, `-moz-opacity`, `-moz-box-shadow`) so Slashdot's sidebar cards render rounded corners without shifting 1-based line/column diagnostic locations.
3. **Inline `<svg>` attributes, large-coordinate `viewBox`, and `viewBox`-only container-width sizing (`crates/mg-sparkle/src/inline_svg.rs`, `images.rs`, `styled_layout.rs`)**:
   - Authored SVG fixtures used small `0 0 24 24` icons without `style="..."` or `xmlns:xlink`, missing Slashdot's social icons (`style="enable-background:..."`, `xmlns:xlink`, `xml:space`, `<defs>`, and FontAwesome `viewBox="0 260 1792 1260"` exceeding `MAX_PIXELS` at 1:1 coordinate rasterization, plus `viewBox`-only `<svg>` without `width`/`height` attributes blowing up to `1792px` coordinate width instead of filling its `20px` flex item). Allowed Stylo `style="..."` and standard XML/SVG namespace attributes on `<svg>` subtrees, added `svg_target_size` proportional scaling within `MAX_SIDE = 2048` / `MAX_PIXELS = 1,048,576`, and extended `is_aspect_ratio_only_svg` + `replaced_size_base` so `viewBox`-only inline `<svg>` elements fill available containing width proportionally.
4. **Desktop viewport (`1280x800`) visual audit across `lobste.rs` and `en.wikipedia.org` (`styled_layout.rs`, `formatting.rs`, `positioned.rs`, `style.rs`)**:
   - `--profile` defaults to `1100x727` (20px narrower than Wikipedia Vector 2022's `@media (min-width: 1120px)` grid breakpoint) and does not inspect rendered pixels. Visual screenshot auditing at `1280x800` caught and fixed three whole-page layout bugs:
     - Inline `position: relative` ancestors on Wikipedia (`positioned.rs`: `resolve_containing_box` now falls back to CSS 2.1 §10.1 inline fragment union instead of aborting styled layout).
     - Vector 2022 `grid-template-areas` / `grid-area` named grid placement (`style.rs`: `grid_style` sizes explicit tracks from `TemplateAreas` and `grid_line` resolves named areas and `-start`/`-end` implicit lines to bounded `GridLine`s).
     - `Taffy` flex-item measurement (`EMIT = false`) leaking `PlacedFloat`s into `paint_allocated` on `lobste.rs` (`styled_layout.rs` / `formatting.rs`: isolated `(self.floats, self.last_float_top)` per BFC measurement/paint pass and included `float_bottom` in measured BFC height).
5. **Real-site Boa JS/DOM & Pinned Playwright `1.58.2` (`F-024`, `F-032`)**:
   - Added byte-length-preserving ECMAScript Annex B `<!--`/`-->` script comments, DOM wrapper expandos, strict/sloppy read-only IDL properties, reflected HTML attributes, `document.currentScript`, `document.write`, and `subdoc:`-backed blank/srcdoc `<iframe>` `contentDocument`/`contentWindow`.
   - Shipped full CDP auto-attachment, isolated utility worlds (including under `--disable-scripts`), `Browser.setDownloadBehavior`, and FD `3`/`4` `--remote-debugging-pipe` + `--headless` mode: both `node tools/playwright/acceptance.mjs` (`http: PASS`, `websocket: PASS`) and `node --test tools/playwright/launch.test.mjs` (`1/1 PASS`) succeed with unmodified `playwright-core` `1.58.2`.
