## Original JavaScript subset and restricted script worker

Continued the active Google-search goal after CDP publication. Added src/js/syntax.rs and runtime.rs: own lexer/parser/tree walker, UTF-16 values, var/function hoisting, closures, basic prototypes/constructors, expression/control/exception semantics and selected builtins. Unsupported syntax/APIs report errors. Execution is a deliberately partial non-strict subset, not ECMAScript conformance; arguments, property descriptors, numeric formatting and host coercion have documented approximations. Logical limits are cumulative across scripts/callbacks: one million fuel, four MiB allocations, 64 calls and bounded objects/arrays. Fatal exhaustion bypasses catch/finally and latches the realm. No imported conformance corpus or garbage collector yet.

src/js_browser.rs adds eligible inline source-order execution after HTML parsing, a shared temporary realm, startup DOMContentLoaded/load callbacks, connected DOM lookup/mutation, script-created forms and validated HTTP(S) navigation proposals. No external scripts, persistent realm, mouse/keyboard script handlers, timers, script cookies or fetch/XHR. Mutated HTML is reparsed by the parent; source/projection rejection returns applied=false, preserves original noscript fallback and discards navigation. Partial execution preserves valid preceding mutations and explicit errors. Browser.getVersion identifies the partial bundled interpreter, but CDP Runtime.evaluate remains -32601 because remote realm/object lifecycles are not implemented.

src/script_worker.rs runs page code only in a fresh restricted Linux x86_64 child, before which the browser clears the environment and uses bounded pipes. Child closes inherited descriptors, sets no_new_privs, CPU/address-space/fd/file limits and an architecture-checked seccomp allowlist before reading page input. New file/socket/process access, executable mappings and weakening confinement are denied. Parent caps request/response JSON at two/four MiB, kills/reaps deadline or output-limit failures, and limits each worker to two seconds wall; child caps one CPU second and 256 MiB address space. Unsupported setup/platform fails closed. libc was already resolved and is now a direct Rust OS-declarations dependency; Cargo.lock changed only the root dependency list. This is script containment, not renderer/network isolation or production hardening.
