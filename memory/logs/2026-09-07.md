The original parser accepts single-binding var or assignable-reference for-in, evaluates its initializer and RHS in order, and rejects for-of and invalid targets. Switch accepts ordered case clauses and at most one default, with strict selector matching, fallthrough and properly scoped break/continue. Function boundaries reset control-flow contexts. Runtime hoisting, AST-size accounting and completion propagation cover both statements. Enumeration snapshots initial visible owner/name pairs across own properties and bounded prototypes, including nonenumerable shadows; only still-visible enumerable pairs are visited. Added names are excluded, deleted or newly shadowed names are skipped, and same-owner delete/re-add may be visited. Virtual array/string indices are ascending; stored properties retain insertion order. Fuel, cumulative logical allocation and prototype-depth limits apply before body execution and remain fatal/latched. Host objects cannot be enumerated. This is a documented subset, not full ECMAScript conformance.

Shared own-property metadata keeps Object.keys/getOwnPropertyNames/hasOwnProperty and for-in consistent for boxed strings, functions and supported native builtins. Boxed-string indices and length remain readonly/nonconfigurable, including inherited access. Native builtin overwrite preserves nonenumerability; delete/re-add creates an ordinary enumerable property. Existing broader descriptor/global/builtin fidelity limitations remain. No dependency, TLS, host capability, script-worker permission or CDP command was changed.
