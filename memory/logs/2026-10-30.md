# 2026-10-30

## v0.9.25: Pure-Rust X11 clipboard (`CLIPBOARD` + `PRIMARY`), mouse text selection, and Cut / Copy / Paste across the entire browser

- User request: enable Copy/Paste (and Cut/Paste where appropriate) across the
  entire browser — specifically DevTools Console error/log entries and inputs,
  other DevTools panels, web pages, `<input>` controls, and the Address bar —
  and ship a verified versioned release (`v0.9.25`).
- Architecture and implementation across `mg-sparkle`, `mg-chassis`, and
  `mg-browser` (zero new crate dependencies; pure-Rust `x11rb` only):
  1. **Positioned Page Text Runs & `<input>` Caret/Selection Rendering (`mg-sparkle`):**
     - Added `TextRun { node, x, y, width, height, font_size, text }`
       (`MAX_TEXT_RUNS = 25_000`) to `Frame::text_runs` across both normal and
       styled layout in `crates/mg-sparkle/src/render.rs` and
       `crates/mg-sparkle/src/styled_layout.rs`, accounting for `TextRun` bytes in
       `Frame::cache_payload_bytes()`.
     - Added `input_selection: Option<(usize, usize, usize)>` to `Controls<'a>`
       and `slice_visible_input(...)` so focused `<input>` fields render partial
       selection highlights and a `2 px` caret while keeping `Controls::default()`
       (headless WPT and no-chrome embedding) 100% pixel-identical.
  2. **App-Wide Selection, Editing & Context-Menu Clipboard Engine (`mg-chassis`):**
     - Created `crates/mg-chassis/src/clipboard.rs` implementing UTF-8 char/word
       cursor navigation, selection range slicing (`slice_line_bytes`,
       `hit_byte_in_line`), `ClipboardUpdate`, `PasteSource`, `PasteRequest`,
       `PageSelection`, `DragTarget`, `ContextKind`, and `SelectionState`.
     - **DevTools Console & Panels (`crates/mg-chassis/src/devtools.rs`, `lib.rs`):**
       - Click or click-and-drag Console log/error rows (`Ctrl+A` selects all
         visible rows); `Ctrl+C`, the subtoolbar `Copy` button, and right-click
         (`Copy message`, `Copy all visible`, `Select all`, `Clear console`) copy
         full untruncated error messages, stack traces, and expanded object
         properties.
       - Synced Console Command Line API `copy(...)` (`ConsoleWireLevel::Copy`)
         directly to the system X11 clipboard queue (`ingest_wire_console_and_sync`).
       - Added full cursor/anchor selection, `Ctrl+A`, `Ctrl+X`/`Shift+Delete`
         (Cut), `Ctrl+C`/`Ctrl+Insert` (Copy), `Ctrl+V`/`Shift+Insert` (Paste),
         and middle-click `PRIMARY` paste across the `>` Console REPL and all five
         `DevToolsField` search/style inputs.
       - Added `Ctrl+C` and context-menu copy across `Elements` (`Copy outerHTML`,
         `Copy selector`, `Copy styles`), `Sources` (click/drag line range +
         `Copy source`), `Network` (`Copy URL`, `Copy details`, `Copy all URLs`),
         `Performance` & `Application` (`Copy report`), and `About` (`Ctrl+C`
         build identity).
     - **Address Bar (`crates/mg-chassis/src/chrome.rs`, `lib.rs`):**
       - First click from a page selects all; second click places caret without
         clobbering on `pointer_up`; drag-select updates `PRIMARY`; double-click
         selects all; supports `Ctrl+A/X/C/V`, middle-click `PRIMARY` paste, and
         right-click `Cut`, `Copy`, `Paste`, `Paste and go`, `Select all`.
     - **Page `<input>` Form Controls & Password Security:**
       - Full cursor/selection/drag/double-click word selection, `Ctrl+A/X/C/V`,
         middle-click `PRIMARY` paste, and `edit_versions` bumping on Cut/Paste.
       - Strict `<input type="password">` protection blocks `Ctrl+C`, `Ctrl+X`,
         drag `PRIMARY` export, and omits `Cut`/`Copy` from password context menus
         while permitting `Paste`.
     - **Read-Only Web Page Prose (`Focus::Page`):**
       - Click-and-drag selection across `Frame::text_runs` with translucent
         selection highlight, double-click word selection, `Ctrl+A` select-all,
         `Ctrl+C` copy in reading order (ignoring Cut/Paste on read-only prose),
         `PRIMARY` update on drag/double-click, and right-click `Copy` +
         `Copy link address`.
  3. **Pure-Rust X11 `CLIPBOARD` & `PRIMARY` Host (`src/platform/clipboard.rs`, `src/desktop.rs`):**
     - Created `X11Clipboard` owning an unmapped `1x1` child window of `screen.root`
       (`EventMask::PROPERTY_CHANGE`) so selection ownership survives closing
       secondary browser windows.
     - Handles outbound `SelectionRequest` (`TARGETS`, `TIMESTAMP`, `UTF8_STRING`,
       `text/plain;charset=utf-8`, `text/plain`, `TEXT`, `STRING`) and
       `SelectionClear`, plus inbound `ConvertSelection` / `SelectionNotify`
       (`UTF8_STRING` with `STRING` fallback, bounded `256 KiB` `INCR` transfers,
       and `0 ms` local short-circuit when `mgbrowser` owns the selection), wired
       to `Button 2` middle-click `PRIMARY` paste and keyboard/menu `CLIPBOARD`
       paste across all workspace tabs.
