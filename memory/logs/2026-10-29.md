# 2026-10-29

## v0.9.24: Six-panel Chromium-style DevTools workspace (`Elements`, `Console`, `Sources`, `Network`, `Performance`, `Application`)

- User goal: ensure the DevTools panel in `mgbrowser` has feature parity with
  Chromium across its panels and debug console, and publish a verified new
  release (`v0.9.24`).
- Architecture and implementation across `mg-sparkle`, `mg-chassis`, and
  `mg-browser`:
  1. **Isolated Boa Worker `console.*` API, Interactive JS REPL & Command Line API (`mg-sparkle`, `mg-browser`):**
     - Added wire-safe `ConsoleWireLevel`, `ConsoleWireKind`, `ConsoleWireEntry`,
       `ConsoleCommand`, `ConsoleResult`, `ConsoleValueKind`, `ConsoleProperty`,
       and `ConsoleCallFrame` in `crates/mg-sparkle/src/page_session/console.rs`.
     - Implemented 19-method WHATWG/Chromium `console.*` API (`log`, `info`,
       `warn`, `error`, `debug`, `dir`, `dirxml`, `table`, `trace`, `assert`,
       `clear`, `count`, `countReset`, `group`, `groupCollapsed`, `groupEnd`,
       `time`, `timeLog`, `timeEnd`) with `%s`/`%d`/`%i`/`%f`/`%o`/`%O`/`%j`/`%c`/`%%`
       substitution in `crates/mg-sparkle/src/js_browser/boa/console.rs`.
     - Value classification and object property previews inspect own property
       descriptors directly (`__get_own_property__` / `PropertyDescriptor::Data`)
       and summarize accessor getters/setters as `[Getter]`/`[Setter]` without
       invoking user JavaScript getters or `Proxy` traps; cyclic object graphs
       are bounded (`[Circular]`).
     - Implemented interactive Console REPL evaluation (`ConsoleCommand::Evaluate`),
       lazy object handle expansion (`InspectObject` up to 128 retained handles),
       and identifier/property completion (`Complete`), plus the Chromium Command
       Line API (`$_`, `$0..$4`, `$(sel, root?)`, `$$(sel, root?)`, `keys()`,
       `values()`, `dir()`, `dirxml()`, `table()`, `clear()`, `copy()`, `inspect()`)
       temporarily installed for non-shadowed bindings and restored after each
       evaluation, with automatic `({...})` object-literal wrapping.
     - Bumped the isolated worker IPC wire `PROTOCOL_VERSION` from `7` to `8` in
       `src/platform/script_worker_session_platform.rs`, forwarding bounded
       `console` entries on every worker reply (`PageStart`, `Dispatch`,
       `PumpTasks`, `Evaluate`, `CallFunctionOn`, `GetProperties`, `Console`)
       under existing 50 ms / 64 MiB RLIMIT_AS / seccomp worker boundaries.
  2. **DevTools Workspace Chrome, Docking, Draggable Splitter & Interactive Element Picker (`mg-chassis`):**
     - Expanded `crates/mg-chassis/src/devtools.rs` and `crates/mg-chassis/src/lib.rs`
       to six panels: `Elements`, `Console` (`Ctrl+Shift+J`), `Sources`,
       `Network` (`Ctrl+Shift+E`), `Performance` (`Ctrl+Shift+P`), and
       `Application`, with adaptive sizing across `400x240` compact (`392 px`),
       `800x600` docked (`352 px`), and `1280x860+` docked (`540 px` right /
       full-width bottom).
     - Added Right/Bottom docking (`DockSide::{Right, Bottom}`, `⬓`/`◨` toggle)
       and live pointer dragging on the 4 px DevTools splitter
       (`on_devtools_splitter`, `drag_devtools_splitter`).
     - Added interactive Element Picker (`↖` / `Ctrl+Shift+C`) with a 4-layer
       Stylo Box Model page overlay (Margin `0xf6b26b`, Border `0xffe599`,
       Padding `0x93c47d`, Content `0x6fa8dc`) and floating `tag#id.class  W×H`
       tooltip; clicking any painted DOM element selects `$0` in `Elements`
       without triggering page links or form controls.
  3. **Six Feature-Rich Panels (`mg-chassis`):**
     - **`Elements` (`Styles` | `Computed` | `Box Model`)**: collapsible `▸`/`▾`
       DOM tree (`Left`/`Right` or click), `== $0` badge, CSS selector & text
       search (`Ctrl+F`), `H` visibility toggle (`display: none !important`),
       `Delete` node removal, live editable `element.style { ... }` declaration
       editor with instant Stylo cache/frame invalidation and worker DOM sync,
       inline RGB color swatches, real Stylo `ComputedStyle` properties via
       `StyleCache::style_for`, and concentric 4-layer Box Model diagram.
     - **`Console`**: live `>` JS prompt, `Tab` ghost autocomplete, 64-entry
       `Up`/`Down` history, `Shift+Enter` multiline editing, clickable `▶`/`▼`
       inline object & DOM property trees, `[Inspect]` jump-to-Elements badges,
       `-term` negative text filter, `All`/`Err`/`Warn`/`Info`/`Verb` severity
       pills, `Preserve log`, and on-demand isolated worker startup
       (`ensure_console_session` with pre-order DFS `$0..$4` node remapping) for
       static or script-skipped oversize pages.
     - **`Sources`**: navigator for `[HTML]` raw source, `[CSS]` inline/linked
       stylesheets, and `[JS]` external/inline scripts with line-numbered
       syntax-colored source view and `Ctrl+F` search.
     - **`Network`**: `All`/`Doc`/`CSS`/`JS`/`Font`/`Img` pills, URL filter,
       `Preserve log`, `Disable cache` (`Session::set_disable_cache`), waterfall
       timeline with `DOMContentLoaded` (blue) and `Load` (red) vertical markers,
       and 4-tab Request Inspector drawer (`Headers` | `Response` | `Preview` |
       `Timing`) with redacted `cookie`, `set-cookie`, and `authorization`
       header values (`crates/mg-chassis/src/net.rs`).
     - **`Performance`**: `● Reload & Profile`, `Clear`, Load Phase Flame Bar,
       64-frame render-duration sparkline with `16.7 ms` (60 FPS) budget line,
       Boa worker opcode/allocation metrics, and frame/style/shaping cache stats.
     - **`Application`**: live session `Cookies` table (`Session::cookies_snapshot`
       with masked byte lengths and `Clear Cookies`), `Security` origin/TLS and
       worker sandbox summary, and `Resources` inventory.
  4. **Release Binary Size Optimization (`Cargo.toml`):**
     - Enabled `lto = "thin"` under `[profile.release]` alongside existing
       `opt-level = "z"` and `strip = "symbols"` (preserving `panic = "unwind"`),
       reducing the packaged archive `mgbrowser-linux-x86_64.tar.gz` to ~`8.21 MB`
       (`8,207,232` bytes), safely below the `8,388,608`-byte (`8 MiB`) updater
       download ceiling.
