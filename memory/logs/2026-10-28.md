## v0.9.23: Google News interactive links/scroll, script-admission preflight, and pure-Rust WOFF/WOFF2 web fonts

- Addressed four user-reported issues and prepared `v0.9.23`:
  1. **Default-mode script-admission preflight (`mg-chassis`):**
     - On `https://news.google.com/` (~1.86 MB wire HTML), default scripting
       prepared external scripts and attempted to start a page session only for
       `MAX_SESSION_HTML_BYTES` (`1 MiB`) to reject `PageStart`, setting
       `script_blocked = true` (`"Page activation unavailable while loading or after script failure"`)
       and emitting `SCRIPT_*` errors.
     - Added `resources::script_document_admissible(page_url, raw_html)` in
       `crates/mg-chassis/src/resources.rs` and wired it into `Browser::navigate_inner`
       (`crates/mg-chassis/src/lib.rs`) when `!observer_active`: oversize HTML
       (`> 1 MiB`) or URLs (`> 4,096 B`) skip external script preparation and
       worker startup up front, parse once with `scripting = false`, report
       `"JavaScript skipped"`, emit zero `SCRIPT_*` errors, and leave
       `script_blocked = false` so scrolling and link activation work normally.
       Pages within admission caps that fail worker startup/execution remain
       blocked (`closed_script_realm_never_falls_through_to_native_activation`
       and `WindowHarness` preserved).
  2. **Google News `/stories/...` (`Full coverage`) styled layout (`mg-sparkle`):**
     - Replaced quadratic `count^3` grid placement estimation with linear
       `O(cells * count + count^2)` preflight in
       `crates/mg-sparkle/src/styled_layout/formatting.rs` so 12-column dense
       `/stories/` grids stay well under `MAX_FORMATTING_WORK` (`16,384`).
     - Extended `CalcOp` (`Linear`, `MinPx`, `MaxPx`) and `parse_outer_calc` in
       `crates/mg-sparkle/src/style.rs` (keeping `size_of::<Length>() == 16`) for
       scalar `Product`/`Invert` and px-bounded `min()`/`max()`/`clamp()` outer
       expressions (`width: min(720px, 100%)` on `/stories/`).
  3. **Pure-Rust WOFF1 (`wOFF`) and WOFF2 (`wOF2`) `@font-face` decoding + synthetic bold/italic (`mg-sparkle`, `mg-chassis`):**
     - Added `#![forbid(unsafe_code)]` `crates/mg-sparkle/src/woff.rs` using
       pinned pure-Rust `flate2` (`ZlibDecoder`) for WOFF1 and `brotli-decompressor = "=5.0.3"`
       (`BrotliState::new_strict` with an 8 MiB `BoundedU8Alloc` and 4 MiB SFNT cap)
       for WOFF2 table directory parsing and transformed `glyf`/`loca`/`hmtx`
       SFNT reconstruction.
     - Updated `font_face_rules` (`crates/mg-sparkle/src/document.rs`) to scan
       multi-`url(...)` `@font-face` `src` lists and accept `.woff2`, `.woff`,
       `.ttf`, and `.otf`; admitted `font/woff2`, `font/woff`, `font/sfnt`, and
       legacy `application/*font*` MIME types in `crates/mg-chassis/src/resources.rs`.
     - Added `ComputedStyle::italic`, UA italic rules (`i, em, cite, dfn, var, address`),
       and `Canvas::text_styled_alpha` (`crates/mg-sparkle/src/paint.rs`) for
       horizontal stem emboldening and subpixel-interpolated oblique shear on
       downloaded `@font-face` families (`synthetic_styles: true`).
