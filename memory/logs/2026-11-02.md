## CSS Visual Parity, HTML5 `<canvas>` 2D, ES Modules, Observers & Desktop UX (`v0.9.30`)

### Intent & Engineering Changes

1. **Responsive CSS Grid, Intrinsic Box Sizing & Visual Rendering (`crates/mg-sparkle/`)**:
   - Implemented explicit `[named-lines]` parsing on `grid-template-columns` / `grid-template-rows`, implicit `<area>-start` / `<area>-end` line synthesis from `grid-template-areas`, `grid-column` / `grid-row` named-line and `span <name>` placement, `fit-content(<length-percentage>)` tracks, and `repeat(auto-fill | auto-fit, ...)` expansion with empty `auto-fit` track collapse (`developer.mozilla.org` renders in full styled Grid layout with `0` layout fallbacks).
   - Generalized `min-content`, `max-content`, and `fit-content` keywords across `width`, `height`, `min-width`, `min-height`, `max-width`, `max-height`, and `flex-basis`, plus HTML5 `<canvas>` `300x150` intrinsic and HTML `width`/`height` attribute sizing.
   - Added analytical rounded-rect signed-distance Gaussian blur `box-shadow` (`0..=8` outer/inset layers), blurred glyph `text-shadow` (`0..=4` layers), multi-stop (`2..=16`) linear/repeating-linear/radial/repeating-radial gradients with color-transition midpoints, CSS 2D `transform` (`translate`, `scale`, `matrix`) with stacking context and `position: fixed` containing-block semantics, `clip: rect(...)` / `clip-path: inset(... round ...)` clipping, and single-line `text-overflow: ellipsis`.
2. **Pure-Rust HTML5 `<canvas>` 2D, Browser ES Modules, DOM Observers & Custom Elements (`crates/mg-sparkle/src/js_browser/boa/`, `crates/mg-chassis/`)**:
   - Built pure-Rust immediate-mode `CanvasRenderingContext2D` (`<= 2048x2048`, `<= 1,048,576` pixels, worker-memory-accounted premultiplied RGBA buffer): rect/path primitives, `Path2D`, nonzero/evenodd scanline `fill` and dashed/joined `stroke`, `clip`, `DOMMatrix` transform stack, `CanvasGradient` / `CanvasPattern`, shadows, Porter-Duff compositing, zero-FD embedded bitmap text, `ImageData` / `drawImage`, pure-Rust LZ77+Huffman PNG `toDataURL` / `toBlob`, and live `document.resources` projection into Sparkle's painter.
   - Added browser-hosted `<script type="module">` preloading (`<= 16` modules, `<script type="importmap">`, live namespace bindings, `import.meta.url`, parent-brokered same-origin dynamic `import()`, UTF-8-safe borrowed-slice module scanning, and lexical `const` binding fast-paths keeping real-world Rspack bundles like MDN below the `64 MiB` cumulative worker allocation limit), `MutationObserver`, layout-synced `ResizeObserver` and `IntersectionObserver`, `CustomElementRegistry` (`window.customElements`), `Element.animate` / `getAnimations`, and `window.visualViewport`.
3. **Real-Site Compatibility, Wikipedia Runtime/Sprite Fixes, Large/Failed-Script CDP Recovery & Desktop Session UX (`crates/mg-sparkle/`, `crates/mg-chassis/`, `src/`)**:
   - Added `@font-face` `unicode-range` codepoint filtering against document text, updated `USER_AGENT` to `"Mozilla/5.0 (X11; Linux x86_64) mgbrowser/0.9.30"` (resolving `www.npr.org` CDN crawler TLS stalls: HTTP 200 in `~288 ms`), and enabled bounded (`<= 128 KiB`, `<= 2,500` nodes) `<script>`-free DOM synthesis for on-demand CDP isolated utility worlds on both oversize (`> 1 MiB`) HTML pages (`news.google.com`, `en.wikipedia.org`) and pages whose script session hit `EngineLimit` or `Terminal` (`developer.mozilla.org`), while preserving `ScriptWorkStatus::Blocked` and post-failure page-activation blocks.
   - Resolved all `www.wikipedia.org` runtime, CSS, and SVG diagnostics: implemented `window.Image` (`new Image(width?, height?)`), raised browser-session `max_listeners` to `2,048` memory-accounted listeners (preserving `32` for standalone `BoaPageRealm::start` contract tests), replaced per-reply full-document `String` serialization (`serialize(0, true)`) with zero-allocation `validate_serialized_bounds(0, true)` plus simple selector fast-paths (cutting `www.wikipedia.org` cumulative worker allocations from `64.3 MiB` to `52.1 MiB`), omitted bogus warnings for zero-alpha `linear-gradient(transparent, transparent)` layers over rendered `url(...)` backgrounds, multiplied `style.color.alpha * opacity` during `Paint::Text` (`color: transparent` fallback text), added bounded SVG `<style>` and acyclic internal `<use href="#id">` decoding, and implemented intrinsic `background-size: auto`, `background-position` offsets, and element-box clipping for CSS background sprites.
   - Added independent per-tab page zoom (`25%..=500%`, `Alt+=` / `Alt+-` / `Alt+0`, `Ctrl+MouseWheel`, address-bar badge, and Menu row), atomic `0o600` (`O_NOFOLLOW`, `flock`, `<= 512 KiB`) persistent `window.localStorage` (`local-storage.json`), and tab session snapshot & restore (`session.json`, Menu -> `Restore session`, `chrome://newtab`, `--restore-session`).
