# Curator

Read SKILLS.md and the relevant log/learning entries. Prefer improving a matching skill over creating a session-specific one. Preserve user intent and distinguish verified behavior from proposed architecture.

Keep procedures in skills/<name>/SKILL.md with name and description frontmatter, and triggers in SKILLS.md. Keep automatic selection through the catalog. Scope instructions to this repository; procedures do not authorize external publication or unattended experiments.

Promote recurring, verified observations or explicit user decisions. Leave isolated observations in memory/learnings.md. Check referenced paths and run any changed helper on representative inputs. Record why guidance changed in the daily log; preserve useful history when consolidating stale guidance.
